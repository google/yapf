# PEP 758: Unparenthesized exception lists

Specification: https://peps.python.org/pep-0758/

Language version: Python 3.14. Branch dependency: the shared grammar-cache isolation fix.

## Supported formatting

Any number of exception types for `except` and `except*`, including a trailing comma; unparenthesized lists cannot bind an `as` target.

New syntax is parsed by the vendored grammar/tokenizer, independently of the
Python version running YAPF. Executing the formatted program still requires a
compatible interpreter. YAPF is a formatter, not a type checker or a replacement
for compiler-level semantic validation.

An unparenthesized list with no explicit continuation remains on one physical
line, even when over the column limit. No implicit parentheses or unsafe line
breaks are introduced. Use an explicitly parenthesized list to enable wrapping.
