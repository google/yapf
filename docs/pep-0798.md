# PEP 798: Unpacking comprehensions

Specification: https://peps.python.org/pep-0798/

Language version: Python 3.15. Branch dependency: the shared grammar-cache isolation fix.

## Supported formatting

List, set, dictionary, and generator unpacking; a generator used as the sole call argument; async comprehensions and conditional generator/mapping heads.

New syntax is parsed by the vendored grammar/tokenizer, independently of the
Python version running YAPF. Executing the formatted program still requires a
compatible interpreter. YAPF is a formatter, not a type checker or a replacement
for compiler-level semantic validation.

## Regression tests

```bash
PYTHONPATH=third_party:. python -m unittest yapftests.pep798_test
```

Tests cover exact output, idempotence, style options, and relevant edge cases.
Native AST/semantic checks run only on an interpreter supporting this PEP;
formatter assertions run on older hosts too.
