# PEP 701: F-string grammar

Specification: https://peps.python.org/pep-0701/

Language version: Python 3.12. Branch dependency: the shared grammar-cache isolation fix.

## Supported formatting

Quote reuse, nesting, comments, backslashes, multiline replacement fields, token positions, and line-range formatting.

New syntax is parsed by the vendored grammar/tokenizer, independently of the
Python version running YAPF. Executing the formatted program still requires a
compatible interpreter. YAPF is a formatter, not a type checker or a replacement
for compiler-level semantic validation.

Interpolated literals remain opaque STRING tokens. Literal text, replacement
expressions, debug-expression whitespace, and template expression metadata are
preserved verbatim. Only surrounding code is reformatted. The scanner identifies
lexical boundaries; it does not validate arbitrary replacement expressions.

## Regression tests

```bash
PYTHONPATH=third_party:. python -m unittest yapftests.pep701_test
```

Tests cover exact output, idempotence, style options, and relevant edge cases.
Native AST/semantic checks run only on an interpreter supporting this PEP;
formatter assertions run on older hosts too.
